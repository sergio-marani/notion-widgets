# Japan Weather and Foliage Widget

A transparent, vertically stacked six-city sidebar widget for a Japan itinerary, embedded in Notion.

## Live URL (after enabling GitHub Pages)

https://sergio-marani.github.io/notion-widgets/customs/japan-weather-foliage/

## Data

Weather and daily history: [Open-Meteo](https://open-meteo.com/). Forecasts are limited by the weather provider's horizon; historical dates for 2025 serve as context, not a forecast.

Foliage: manually dated seasonal estimates in `index.html`, requiring updates when new bulletins are published. The colors are not live foliage measurements.

GitHub Pages: publish `main` branch from repository root.
